Fonts embedded into the character sheet PDF (pdf_render.go).

Static instances of the Google Fonts variable fonts, subset to Latin, Latin Extended,
Cyrillic, punctuation and a few symbols (fontTools instancer + subset):

- Cinzel Bold — section titles and labels (no Cyrillic: only fixed English labels)
- Inter Regular / Bold / Italic — numbers, tables, tags
- EB Garamond Regular / Bold / Italic — names and descriptions
